# 🕒 SyncTime

Um relógio digital simples desenvolvido com **HTML, CSS e JavaScript**.

## 📖 Sobre

Este projeto exibe um relógio digital em tempo real, formatado no padrão **HH:MM:SS**, com um design moderno e responsivo.

## 🚀 Tecnologias

- **HTML** → Estrutura da página
- **CSS** → Estilização e responsividade
- **JavaScript** → Atualização do horário em tempo real
- **Fonte Rampart One** → Usada para estilizar o relógio

## 📂 Estrutura do Projeto

/synctime  
**│── index.html** → Estrutura principal  
│── **/src** → Pasta de arquivos do projeto  
│ ├── **/css** → Estilos do relógio  
│ │ ├── **style.css** → Arquivo principal de estilos  
│ │ ├── **mediaQueries.css** → Aquivo de responsividade  
│ ├── **/js** → Scripts do relógio  
│ │ ├── **script.js** → Lógica para atualização do tempo  
│ ├── **/fonts** → Fonte Rampart One usada no projeto  
└── **README.md** → Documentação do projeto

## 📦 Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/oTiagoPereira/SyncTime.git
   ```
   Acesse a pasta do projeto:

#### cd synctime

Abra o arquivo index.html no navegador.

### 🎨 Layout

O relógio utiliza a fonte Rampart One, importada na pasta fonts. O design pode ser facilmente alterado no arquivo style.css.
